## Issues I accept

**Bugs (fix next, in this order):**

1. **Docs/man lie about prefetch default 4** while `-h` and `k_prefetch_default` are 6 (`man/tdx.1`, `man/iron86.1` OPTIONS, `cpu.h` Doxygen). Confirmed.
2. **`getip`/`status` always `"stop":1` (STEP)** while F9 is live (`rex_sock.cpp:1329`). Confirmed in play; agents misread pause.
3. **Default socket `unlink`+bind** steals `/tmp/tdx.sock` (`rex_sock.cpp` listen). Confirmed this session.
4. **HDC `dma_from_memory` ignores 8237 count** (`hdc.cpp:692`); read path clamps (`:667`). Confirmed. Latent until a short DMA write.
5. **FDC Write 05h/09h ST0=success, no DMA** (`pc.cpp` ~2069). Both reviewers. COPY/saves can lie.
6. **iron86 CLI `--bios` never `wall_clock_irq0`**. tdx `pit_poll` does. Standalone iron86 timer is dead for reload-0. DIR C: was tdx-only.
7. **tdxview F9 sends `run` (toggle)** — can pause a running CPU window.
8. **`--hdc` empty-BIOS error text** is “need --preset ibm-xt” when the real failure is “default 5160 ROM not found”. `--hdc --no-bios` same message.

**Suggestions (true, not blockers):** `40:75=1` even without HDC; INI CHS unbounded; `attach()` fopen before fstat (CLI already refuses); `--until-prompt` only B800 `A>`; tdxctl `type` missing from man; CLI.md omits tdx `--hdc`; headless `unpause` no-op without `--run`.

**Nits:** dead `remaining==0` after uint32 add; guard `--hdc=` vs loop devices; `--scale=` form.
