# IBM 5160 BIOS 10JAN86 — label map

**ROM:** `tests/images/hdc-proof/xt5160_10jan86_64k.bin` (64 KiB)  
**SHA256:** `cfa8f89cc4e765901321a26e619bde346740c41eefddd5beb37314e9dffd107e`  
**Addressing:** `F000:IP` = file offset `IP` = phys `0xF0000+IP`.  
**Verified:** Capstone 6 + ndisasm against this file. IBM names from XT BIOS V2 listing (`/mnt/linux/docs/research/IBM-PC-BIOS/IBM PC XT/XT BIOS V2/`), checked against **our bytes**.

Layout of this 64K image:

| File / IP | Contents |
|-----------|----------|
| `0000–1D36` | BIOS proper: HEADER, DSKETTE, KEYBRD, PRT, RS232, VIDEO, BIOS1 (INT 15) |
| `1D37–5FFF` | INT3 fill (`CC`) — `FILL.ASM` `42C9h` bytes, lands on `6000` |
| `6000–DFFF` | Cassette BASIC C1.10 (`The IBM Personal Computer Basic`, 25-Apr-81) |
| `E000–FFFF` | POST + compatibility ORGs (`POST.ASM`) |
