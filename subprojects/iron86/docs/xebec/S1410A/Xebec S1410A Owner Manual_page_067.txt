.5.3.11        Write (Class 0, Opcode OA)
This command will write   from   1 to 256 sectors as
specified by the byte 4 of the DCB, starting at the
address specified by the bytes 1, 2 and 3 of the DCB. The
multiple sector transfer scheme works the same as the
READ command.    There is no read verify of data on a
write command, (therefore, no ECC errors).
