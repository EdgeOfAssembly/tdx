.5.3.12       Seek (Class 0, Opcode OB)
This command initiates a seek to the track specified in
the DCB. The drive must be formatted. If buffered step
option is selected then the Controller will issue the seek
step pulse and complete the command before the drive
completes the seek. This allows overlap seek operation.
d = drive, 0 or 1
r = retries
S = seek option
