.5.3.7
Format Track (Class 0, Opcode 06)
This command recalibrates the drive, seeks to the target
track specified in byte 1, 2 and 3 of the DCB, and writes
the ID and   DATA fields with   the   interleave   value
specified in byte 4 of the DCB.    This command can be
used to clear the defective or alternate track bits, or to
reformat one track that lacks data integrity on a drive.
d = drive, 0 or 1
r = retries
P = format pattern (Ref:    Bit 5 of the control byte of the
FORMAT DRIVE command)
V = drive type (Ref:   Bit 4 control byte of the control byte of
the FORMAT DRIVE command)
S = step option
