5.3.8
Format Bad Track Class (Class 0, Opcode 07)
This command is the same as FORMAT TRACK command
except the BAD TRACK flag is set in the ID field. DATA
fields are not written.   This command is used to prevent
system access to defective tracks.   There is an alternate
way to process bad tracks. See the ASSIGN ALTERNATE
TRACK Command for details.
