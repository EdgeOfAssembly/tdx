4.5.3.17       Read Sector Buffer (Class 0, Opcode 10)
This command is used in 2 ways:
A)      Read the contents of the data buffer after writing it
using WRITE SECTOR BUFFER command to test
the RAM.
B)      If an uncorrectable data error occurs, the Controller
will not send data to the host, but reports the error
immediately.    If the host wants the corrupt data,
the host issues this command to retrieve it.
