4.5.3.21       Drive Diagnostic (Class 7, Opcode 03)
This command tests both the drive and the drive-to-
controller interface. The controller sends recalibrate and
seek commands to the selected drive and verifies the ID
field of sector 0 on all tracks on the disk. The controller
does   not   perform   any   write   operations   during   this
command; it is assumed that the disk has been previously
formatted.
