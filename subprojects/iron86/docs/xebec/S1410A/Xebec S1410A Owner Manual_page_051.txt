The address valid bit in the error code byte (bit 7) is
relevant only when the previous command required a
logical block address; in which case it is always returned
as a one, otherwise it is set to zero.   For instance, if a
Recalibrate   command   is   followed   immediately   by a
Request Sense Status command, the address valid bit
would be returned as zero since this command does not
require a logical block address to be passed in its DCB.
